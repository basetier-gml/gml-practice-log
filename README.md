# GML 练习记录站

一个**单文件**的 GameMaker / GML 练习记录本：把写过的 GML 代码、踩过的坑、用过的官方 API 记下来，
还能让 AI 直接读这个页面、帮你把一句「玩家无敌时间不对」定位到具体文件和行号。

- **打开就能用**：整个站点就是一个 `index.html`，双击即开，不需要服务器、不需要注册、不联网也能用。
- **数据在你自己浏览器里**：localStorage 存储，页面里没有任何上报逻辑。
- **给 AI 用的接口**：页面内置一份 AI skill，并暴露 `window.gml.cmd(...)` 命令接口，AI 不必去抠 DOM。

在线版：<https://basetier-gml.github.io/gml-practice-log/>

## 快速开始

```bash
# 1. 直接打开（推荐）
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows

# 2. 或者起个本地静态服务
python3 -m http.server 8080
# 然后访问 http://localhost:8080/
```

打开是**空站**（不带任何记录）。两个入口：

- **菜单 ▾ →「新手教程」**：一键加载 6 条用法说明记录 —— 四种用法各一条、API 库怎么用、
  站点怎么操作，外加一条「点菜单里的清空，正式开始使用」。
  说明会**按当前界面语言**加载（中文 / English 各一版），而且**就是打卡记录**，
  和你自己写的记录长得一样；看完在菜单里点「清空缓存」删掉即可。
- **「＋ 打卡一次」**：直接开始记自己的练习。

### 演示模式（详情态标题栏）

打开一条练习的详情后，标题栏「存读档」**左边**有个「演示模式」按钮：

- 点开是**占满屏幕**的演示界面；
- **记录名称和练习题要求直接可见**；**练习题提示**、操作描述、代码、对象、变量表、
  API 参数说明这些**手写的内容先藏起来**（超链接的网址直接显示，不藏）；
- **点一下某一段隐藏的文字**，它会用打字机逐字打出来；
- **再点一下**同一个位置，立刻显示这一段的全部内容；
- 同一时刻只会有一个打字机在跑（**在别处触发时，前一个直接显示完整内容**，不停在半截）；
- 打字时**新打出来的字不会跑出屏幕**（内容变高时自动往下滚）；
- 触发打字机时，**那一块会被移到画面中央**（底部预留了半屏空间，滚得到中间）；
- 打字机**播放完毕或被打断**时，**如果那一块贴近屏幕底部、且距离小于抬升高度**，
  就会触发一次**上抬**：抬升高度 = **文字高度 × 2.5**（文字高度跟着画面缩放一起放大），
  块的底边停在「屏幕下沿往上一个抬升高度」的地方；不贴近底部就不动；
- 顶栏可以**自定义打字速度**（毫秒/字，改完立刻生效）；
- 顶栏打字速度**左边**有 3 个**倍数**按钮：**1倍 / 1.5倍 / 2倍**
  —— 整体放大：字号、行高、内边距、卡片高度一起放大（文字按新字号真排版，不是压扁画面）；
  **手机竖屏只放大字体**（排版宽度不动，元素边界不被横向拉宽），
  其它屏幕则连元素边界一起拉开；竖向不设限（高度随内容长）；
  **默认档位：手机竖屏 1 倍，其它情况 2 倍**（打开演示时自动套用）；
- **模块载体默认全藏着**，「用到的代码载体」那里有个「显示载体」按钮，**点一次放出来一个**；
  **代码框初始只显示第一行**，点它开始打字时一行一行展开；
  按钮始终跟着最新出来的载体走，**打字时也不会被顶出屏幕**；
- 关掉演示界面就退出演示模式（关闭按钮 / 点遮罩 / `Esc`）。

适合录屏、给别人讲一遍、或者把一段代码"现场敲出来"。

## 四种工作模式

站点支持三种用法，三条纪律各有侧重：

### ① 打卡模式 —— 录一份写好的成品

把已经做完的东西录进来：描述 + 代码 + 用到的官方 API。

```js
await window.gml.cmd('checkin', { name:'俯视角射击 demo（成品）', requirement:'…', hint:'…' })
await window.gml.cmd('addModule', { type:'脚本', value:'// 文件名\n<代码>' })
await window.gml.cmd('addApi',   { code:'draw_text', desc:'画一行字' })
await window.gml.cmd('refApi',   { code:'draw_text' })
await window.gml.cmd('finish')
```

- 官方 API：**登记 + 引用**。
- 自写类 / obj：**只登记它自己**（`addApi`），**不做跨记录引用** —— 成品没有「按环节演进」的过程。

### ② 日志模式 —— 按功能环节记开发过程

一个功能环节 = 一条记录，**测通过了才打卡**。这时额外有「定义它的环 / 用到它的环」之分：

- 自写类 `class_hp`：**定义它的环 + 用到它的那些环，都要 `refApi` 引用它**；
- 被创建的对象 `obj_player` 同样登记并被引用，方便反查「哪个 obj 被哪些记录用过」；
- 类的 static 方法（`class_gun.fire`）**默认不单独登记**，只有出现在自己文件之外（类外复用）才登记；
- **每打一次卡立刻 `export` 存一次档**（防中途丢），写完用 `get` 读回核对。

### ③ 教程模式 —— 一个操作步骤一条记录

把一段教程/课程整理成可跟着做的步骤，每步一条记录：

- **题目要求只写要求**（要做成什么样 + 怎么验收），**不写操作步骤、不贴代码**；
- **操作步骤 = 多段「操作描述」载体 + 代码 / 对象载体**，按步骤顺序**交错**排列
  （先说这一步做什么，紧接着给这一段的代码）；
- **操作描述只说动作，不贴代码**：赋值语句和 API 调用一律归代码 / 对象载体；
- **正文要主动分段**：一个意思一行，别让浏览器在句子中间折断。

### ④ 演示模式 —— 把一条练习做成解读视频

给 AI 下达「把这条练习演示出来 / 录一段讲解视频」时，它会：

1. 用 `get` 读回这条记录，**生成一版解读稿**（分段、每段对应页面上的一块）；
2. **把稿子给你确认**（你点头或改完才继续）；
3. 打开这条记录的**演示模式**，按稿子逐段触发对应位置的**打字机特效**；
4. **录屏**（Playwright `recordVideo`）→ **TTS 逐句配音** → **ffmpeg 剪辑**成片。

**一段的固定顺序**：打字机一开始 → 配音同时开口 → 谁先结束谁等谁 →
打字机走完 + 台词说完，才切下一个打字机、开始读下一段台词。
台词比打字机短时，合成阶段会**压缩这一段的视频**（`setpts`），配音时长不动。

演示模式里可用的命令（AI 用它们驱动整个流程）：

| 命令 | 参数 | 作用 |
|---|---|---|
| `demo` | `{open}` / `{close}` / `{speed}` / `{ratio}` | 打开/关闭演示、打字速度、倍数（1倍·1.5倍·2倍） |
| `demoReveal` | `{index}`（不给就放下一个） | 放出一个代码载体（演示里默认全藏着） |
| `demoBlocks` | – | 列出可触发打字机的块（序号 / 预览 / 状态） |
| `demoType` | `{index}` 或 `{match}` | 触发打字机；**默认等它打完再返回**（分镜节奏） |
| `demoCoverage` | `{covered:[块序号…]}` | **覆盖检查**：返回还有哪些隐藏块没被讲到（`missing`） |
| `mode` | – | **只在生成的手册文件里**：当前模式 `manual`（只读手册）/ `full`（完整功能）。原始 index 里没有这条命令 |

完整流程见页面内嵌 skill 的 §8.7。

### 三条通用纪律

1. **先测通、再打卡** —— 先打卡后补测，记录里就混进了没验证过的环节；
2. **每打一次卡立刻 `export`**；
3. **写完 `get` 读回核对** —— 写没写错，机器说了算。

## 命令接口（给 AI 用）

页面加载完就有 `window.gml.cmd(name, args)`，返回 `{ ok:true, ... }` 或 `{ ok:false, error:'…' }`。

| 命令 | 作用 | 参数 |
|---|---|---|
| `state` | 看当前状态（昵称 / 设置 / 记录列表 / API 列表 / 当前打开的练习） | — |
| `checkin` | 打卡一次，建一条记录 | `{name, requirement, hint}` |
| `set` | 改当前记录的字段 | `{name?, requirement?, hint?}` |
| `addModule` | 加一个代码载体 | `{type, value}`，`type` ∈ 脚本 / 对象 / 操作描述 / SVG绘图 / 超链接 / 着色器 |
| `addObject` | 加对象载体 | `{name, fields:[], events:[{name, code}]}` |
| `addApi` | 登记一个 API 条目 | `{code, desc, params?}` |
| `refApi` / `unrefApi` | 引用 / 取消引用一个 API | `{code}` |
| `get` | 读回一条记录全文 | `{id}` 或 `{name}` |
| `select` | 选中一条记录并打开详情（演示前要先选） | `{id}` 或 `{name}` |
| `find` | 把一句反馈定位到具体代码位置 | `{q}` |
| `remove` | 删一条记录（破坏性，必须指明 id 或 name） | `{id}` 或 `{name}` |
| `export` / `import` | 整站存档导出 / 导入（导入只有覆盖，两次确认） | `import: {json}` |
| `exportPractice` | 导出某一条练习（含它引用的 API） | `{id}`（**不传就是当前打开的那条**） |
| `shareLink` | 生成分享链接（网址 + `#gmlp=<压缩包>`） | — |
| `screenshot` | 生成练习过程长图（1440px，二维码固定在开头） | — |
| `setNick` / `setAvatar` | 改昵称 / 头像 | `{name}` / `{dataUrl}` |
| `lang` | 切换中英 | `'zh'` / `'en'`（或 `{lang:'en'}`） |
| `finish` / `close` | 结束编辑（弹层不关） / 关闭弹层 | — |
| `clear` | 清空整站（**只在用户明说重开时用**） | — |

### `find` —— 把反馈定位到代码

```js
await window.gml.cmd('find', { q:'cd_max' })
// → { ok:true, q:'cd_max', total:3,
//     records:[{ id, name, hits:[{ where:'class_gun.gml > fire', file:'class_gun.gml', line:28, text:'…' }] }],
//     apiHits:[{ code:'class_gun', desc:'…', where:'code' }] }
```

子串匹配、大小写不敏感，同时搜要求 / 提示 / 脚本载体 / 对象事件 / API 库。
返回的 `where` 优先给「文件 > 类 > 方法」的路径，`file` 是工程里的文件名，`line` 是行号。

## 教程手册模式（另生成一个文件，**原始 index 不动**）

这个站的 index 是**你的练习本**（打卡 / 编辑 / 导入 / 扫码 / 删除都留着）。
需要「一本教程手册网页」时，**另生成一个独立的只读 HTML 文件**交付：

```bash
python3 <skill:gml-tutorial-manual>/scripts/build_manual_site.py \
  --records chapters.json --out /path/to/manual/index.html --title "手册名"
```

- `chapters.json` = `{title, records:[{name, requirement, hint, modules:[…]}]}`；
  **数组顺序 = 章节顺序**（第 1 个元素 = 第 1 章 = 最左边）；
- 脚本：读原始 index → 打上「手册模式补丁」→ 灌内容 ⇒ **原始 index 一个字都不动**；
- 生成的手册里：没有头像 / 菜单 / 打卡页 / 导入 / 扫码 / 编辑 / 删除；
  日期显示成「第 N 章」，**先创建的章节排在最左边**；
  宽屏保持左右分屏（左：章节列表 + API 库；右：练习过程＝这一章的正文），窄屏点章节弹层打开；
- 手册文件自己带一条 `mode` 命令，可以自报当前模式；
- 手册的**存档直接写进 HTML 文件本身**（不落 localStorage）⇒ 看手册不会往你的练习记录里塞章节，
  你练习记录里的东西也不会顶掉手册内容（同一浏览器里开也一样）；打开手册后浏览器缓存仍然是空的。

## 存储与数据安全

- **本项目的数据只在自己的命名空间里**：`gml-practice-log-v2:`（`:user` `:settings` `:records` `:days` `:api` `:apiIndex` `:cleared` `:preImport`）。
- 菜单「清空缓存」/ 命令 `clear` **只删这些键**，**不会调用 `localStorage.clear()` 整片清空** ⇒ 同一域名下别的应用的数据不受影响；Cache Storage 也只删本项目自己建的。
- 存储写不进去（配额满 / 隐私模式禁写）会**明确弹提示**，并提醒你导出备份，不会静默丢数据。
- 导入前先校验：不像存档的、坏 JSON 一律拒绝，**现有数据不动**；覆盖前自动留快照，导错了用命令 `restore` 回滚。
- 重复导入同一份存档不会重复写；导入时会提示重复 ID / 内容冲突。

## 数据与隐私

- **全部存在浏览器 localStorage**，键名前缀 `gml-practice-log-v2:`，分 `user` / `settings` / `records` / `days` / `api` / `apiIndex` 六片。
- **没有任何上报 / 统计 / 广告代码**，断网可用。
- 导出是纯 JSON 存档（`{app, version, exportedAt, counts, data}`），可以直接备份、可以贴给 AI 看。
- 换浏览器 / 换设备：用 **导出 → 导入** 搬过去（导入只有覆盖，会提示两次）。
- 昵称和头像**不会被语言切换替换**（不会被 i18n 遍历器误伤）。
